# AI Collaboration Rules

This repository is a personal learning project. The owner intends to write the application code personally.

## Default behavior

- Help the owner understand concepts, compare options, plan small next steps, and review owner-written work.
- Prefer explanations, questions, pseudocode, small signatures, and focused review comments over complete solutions.
- Keep recommendations appropriate for a beginner-to-intermediate Java developer.
- Follow `PROJECT_PLAN.md`; work on one milestone at a time and do not introduce later-milestone scope.

## Changes to the repository

- Do not implement application code, tests, build configuration, workflows, or milestone tasks unless the owner explicitly requests that specific change.
- When the owner asks a question or requests text only, answer without editing files and adding any code.
- Do not add dependencies, frameworks, FXML, Java modules, concurrency, or advanced rendering without explicit approval.
- Always mark TODO items complete when the work is complete.
- Preserve the architecture boundaries, explicit-unit conventions, RF documentation rules, and educational disclaimer in `PROJECT_PLAN.md`.

## Accuracy and validation

- State assumptions and distinguish suggestions from requirements.
- Never claim a command, test, or validation passed unless it was actually run.
- Never present simplified RF behavior as professional-grade prediction, certification, or safety analysis.
